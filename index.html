ImageTools

ブラウザだけで動く画像処理ツール集です。ファイルはアップロードされず、処理はすべて手元のブラウザ内で行われます。

  • Aseprite シート変換

    .ase / .aseprite ファイルを読み込み、レイヤーの表示切替やセル分割をしてスプライトシートPNGとAseprite互換JSONに書き出します。

    入力
    .ase / .aseprite
    出力
    PNG, JSON (Aseprite互換)
    tools/aseprite-sheet-converter.html

  • Keyout Sprite Packer

    連番PNGのキーカラー(マゼンタ等)を透過に変換し、1枚のスプライトシートにまとめます。1枚だけ渡すと既存シートの透過処理のみ行います。

    入力
    PNG / BMP (連番または1枚)
    出力
    PNG, JSON (独自形式 / Aseprite互換)
    tools/keyout-sprite-packer.html

  • アイコン一括生成

    1枚の元画像から favicon・iOS・Android・Windows 用のアイコンを各サイズまとめて作り、ZIPで保存します。余白・角丸・背景色・ドット絵向けの縮小も選べます。

    入力
    PNG / JPG / WebP / SVG (1枚)
    出力
    ZIP (PNG, ICO, webmanifest, Contents.json)
    tools/icon-generator.html

  • 揺れものアニメーター

    1枚絵の髪・服・体などに揺れ領域を置き、バネの揺れと膨張・縮小でループするアニメーションを作ってスプライトシートに書き出します。ドット絵はドットを崩さずに変形します。

    入力
    PNG / JPG / WebP など (1枚)
    出力
    PNG, JSON (Aseprite互換)
    tools/jiggle-animator.html

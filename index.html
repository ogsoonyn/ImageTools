ImageTools

ブラウザだけで動く画像処理ツール集です。ファイルはアップロードされず、処理はすべて手元のブラウザ内で行われます。

  • Aseprite シート変換

    .ase / .aseprite ファイルを読み込み、レイヤーの表示切替やセル分割をしてスプライトシートPNGとAseprite互換JSONに書き出します。

    入力
    .ase / .aseprite
    出力
    PNG, JSON (Aseprite互換)
    tools/aseprite-sheet-converter.html

  • スプライトシート作成

    連番画像やスクリーンショット(Ctrl+V で貼り付け)を並べてスプライトシートにまとめます。キーカラーや背景の透過、暗い部分を透明にする加算素材向けの変換、共通範囲での切り出し、足元などでの位置揃え、コマごとの微調整ができます。できあがったシート1枚の透過だけも行えます。

    入力
    PNG / BMP / JPG など (複数)、クリップボードの画像、シート1枚
    出力
    PNG, JSON (Aseprite互換)
    tools/sprite-sheet-maker.html

  • アイコン一括生成

    1枚の元画像から favicon・iOS・Android・Windows 用のアイコンを各サイズまとめて作り、ZIPで保存します。余白・角丸・背景色・ドット絵向けの縮小も選べます。

    入力
    PNG / JPG / WebP / SVG (1枚)
    出力
    ZIP (PNG, ICO, webmanifest, Contents.json)
    tools/icon-generator.html

  • 揺れものアニメーター

    1枚絵の髪・服・体などに揺れ領域を置き、バネの揺れと膨張・縮小でループするアニメーションを作ってスプライトシートに書き出します。ドット絵はドットを崩さずに変形します。

    入力
    PNG / JPG / WebP など (1枚)
    出力
    PNG, JSON (Aseprite互換)
    tools/jiggle-animator.html

  • コマ整列ツール

    1枚の画像にバラバラに置かれたアニメのコマを背景色から自動で見つけて切り出し、アニメごとに格子状のスプライトシートへ並べ直します。結合・削除・並べ替え・アニメ分けを手で直せます。

    入力
    PNG / BMP / JPG / WebP (1枚)
    出力
    PNG, JSON (Aseprite互換)
    tools/frame-sorter.html

  • ドット絵拡大ツール

    ドット絵を整数倍に拡大します。最近傍・Scale2x/3x・xBR の結果を左右に並べて見比べられ、1ドットの輪郭を細いまま保つこともできます。スプライトシートはコマごとに拡大できます。

    入力
    PNG / GIF / WebP など (1枚)
    出力
    PNG
    tools/pixel-upscaler.html

  • ドット絵 中割りツール

    2枚以上のキー絵から、間をつなぐ中割りを自動で作ります。キー絵にある色だけを使うのでドット絵らしさを保ち、できたコマは1ドット単位で手直しできます。

    入力
    PNG など (複数、またはシート1枚)
    出力
    PNG, GIF, APNG
    tools/pixel-inbetween.html

  • シート仕上げ

    できあがったスプライトシートを、コマの並べ替え・位置合わせ・ドット修正・フィルタ・表情差分の追加で仕上げます。編集しながらアニメーションを確認できます。

    入力
    PNG など (シート1枚) + JSON
    出力
    PNG, JSON
    tools/sprite-polish.html

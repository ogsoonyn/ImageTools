揺れものアニメーター

1枚絵の髪・服・体などに揺れと膨張・縮小を付けて、ループするスプライトシートを書き出します。処理はすべてブラウザ内で完結します。

入力

未読み込み

画質

最近傍で取り、揺れ幅を整数ピクセルに丸めます。新しい色は増えません。

体の動き

フレーム

余白は揺れや体の動きではみ出さないように、各フレームの四辺に足す幅です。

出力

—

JSON は Aseprite の配列形式(frames + frameTags)です。

編集

中心の丸をドラッグで移動、四角で幅と高さ、ひし形で根元の位置を変えます。

プレビュー

0 / 0

—

一時停止中はプレビューをクリック(または ← → キー)でコマ送りできます。

揺れ領域

「領域を追加」で揺らす範囲を置きます。

範囲

揺れ(バネ)

速さは1ループの間に揺れが往復する回数です。枚数や再生速度を変えても動きの中身は変わりません。収まりやすさを上げると揺れがすぐ止まります。

変形(拡縮)

膨張・縮小は1周期で膨らんで(縮んで)元に戻り、膨張縮小は両方を交互に行います。

アイコン一括生成

1 枚の元画像から favicon・iOS・Android・Windows 用のアイコンをまとめて作り、ZIP で保存します。処理はすべてブラウザ内で完結します。

入力

未読み込み

出力するアイコン

調整

0%
0%
50% で円になります。iOS / apple-touch-icon / maskable には角丸を付けません(OS 側で丸めるため)
背景
透過のままでも、透過できない出力(iOS など)はこの色で塗ります
縮小方式

Web マニフェスト

出力

プレビューのアイコンをクリックすると、その1枚を「PNGを保存」で保存できます

プレビュー

—

元画像を読み込むと、各サイズのアイコンがここに並びます

HTML スニペット


        
ZIP の web/ フォルダの中身をサイトのルートに置き、この内容を <head> に貼り付けます

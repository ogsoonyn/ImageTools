シート仕上げ

できあがったスプライトシートのコマを並べ替え・位置合わせ・ドット修正して、同じ形式で書き出します。処理はすべてブラウザ内で完結します。

入力

未読み込み

サンプルはわざと崩してあります。5コマ目が右にずれ、6と7コマ目が逆順、3コマ目にゴミ点があります。

分割

ファイル名の最後の「列x行」（例: walk_4x2.png）で自動で分割します。読み直しも「元に戻す」で戻せます。

書き出し

1アクションを1行に並べます。列数は一番長いアクションのコマ数です。差分の行は「アクション名_差分名」になります。

保存は右上の「PNGを保存」「JSONを保存」から。

JSON は Aseprite 互換（frames + frameTags）。アクションは frameTags に、表示時間は duration に入ります。

セルの大きさ

余白を足す・削ります。絵は基準の位置に合わせて置き直します（はみ出した所は書き出しで切れます）。

背景を透過

#ffffff

作業の保存

コマ・差分パーツ・表示時間などを1つの JSON に保存します。続きはそのファイルをドロップすると開けます。編集内容はこのブラウザにも自動で残ります。

コマ一覧 0

1行が1つのアクションです。クリックで選択、Shift で範囲、Ctrl で追加選択。ドラッグで並べ替え（別の行へ落とすとそのアクションに移ります。選んだコマはまとめて動きます）。行の名前をクリックするとその行を全部選びます。

絵の位置を揃え直す（全コマの絵が収まる枠をセル中央に置き、その中で揃えます）

表情差分

差分パーツは元の絵の上に重ねます（透明な所は元の絵が見えます）。位置はコマごとに持ち、「パーツを描く」中は「コマを動かす」や矢印キーでパーツの位置が動きます。元の絵を直すと、すべての差分に反映されます。
